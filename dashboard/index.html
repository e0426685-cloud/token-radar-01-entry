Launch Radar

Protocols that record no token yet, ranked by what their launch would be worth — and how to farm each one.

How the radar prices a launch

A protocol with no token has no market price, so the radar prices it from its neighbours: the protocols in the same snapshot whose tokens already trade. For each category it takes the median market-cap-to-TVL ratio of those live peers, applies the ratio to the pre-token protocol's own TVL, then adjusts for seven-day TVL momentum, for how long the protocol has run with no token, and for how many chains it serves. Wrapped, staked, bridged and exchange-house products of traded tokens are set aside — their launch already happened under another name. Implied value is this entry's own estimate, not a prediction that a token will be issued.
